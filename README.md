# 中青年人群肥胖风险预测系统 (A Prediction System for Chinese Adults' Obesity)

基于中国中青年人群饮食行为与肥胖关系研究训练的随机森林模型，供研究与科普展示使用的静态网页原型。

## 说明

- 纯前端实现（HTML + CSS + 原生 JS），所有推理在浏览器本地完成，不上传任何用户数据。
- 模型：RandomForest，通过嵌套交叉验证网格搜索确定超参数。
- 纳入变量：膳食模式得分、运动习惯、肥胖家族史、EBQ-18 进食行为总分、吸烟状态。
- 三个页面对应研究里三种独立的膳食模式测度方式，页面顶部可互相切换：

  | 页面 | 膳食模式测度方式 | 网页内得分公式精度 | 独立测试集AUC |
  |---|---|---|---|
  | [index.html](index.html) | EFA模式一 | 精确重构（OLS反推，R²≈1.000） | 0.938 (0.907–0.964) |
  | [mode2.html](mode2.html) | EFA模式二 | 高精度近似（R²=0.994，非精确重构） | 0.931 (0.897–0.961) |
  | [entropy.html](entropy.html) | 熵权法 | 高精度近似（R²=0.980，非精确重构） | 0.932 (0.900–0.960) |

  模式二和熵权法的严格计算需要78个原始食物题项，为保持三个页面统一的"13个食物大类频率"输入体验，
  这两个页面用训练数据对"膳食得分~13个食物大类均值得分"做OLS回归得到的近似线性公式，
  与真实得分存在细微误差（R²已在上表标注），页面内"关于本模型"部分也做了同样说明。
- 每个页面对应的 `model_*.json` 由训练脚本导出（300 棵树的分裂结构 + 标准化参数），
  各自的 `script*.js` 中的推理逻辑均已与 scikit-learn 原始 `predict_proba` 输出逐样本核对一致。

## 本地预览

用任意静态文件服务器打开本目录即可，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。
